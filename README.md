# Shraddhanjali Choudhury

Personal academic website — live at https://shraddhaqdot.github.io

- single-page layout with anchored nav (About / News / Research / Background / Honors)
- light/dark theme toggle
- plain HTML & CSS, works on GitHub Pages without any build tooling

## Updating

Everything lives in `index.html`. To add a news item, copy one `<li>` inside the `#news` list;
to add a paper or project, copy one `<div class="pub">` block inside `#research`.

Put your CV in the repo root as `cv.pdf` so the "↓ CV" button works.
